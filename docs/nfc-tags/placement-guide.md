# NFC Tag Placement Guide

This document provides best practices for physically placing NFC tags in the environment.

Good placement makes the hunt magical.
Bad placement makes it feel like IT support.

---

## 1. Core Principles

- Tags should be discoverable, not obvious
- Scanning should feel intentional
- Players should not need to contort themselves
- Phones should not be placed near water unless narratively justified

---

## 2. Recommended Heights

- Adult reach: 36–60 inches
- Kid-friendly reach: 24–48 inches
- Avoid floor-level placement unless protected

---

## 3. Surface Guidelines

Best surfaces:
- Wood
- Painted drywall
- Plastic
- Glass (with adhesive backing)

Avoid:
- Bare metal
- Thick stone
- Behind mirrors unless tested
- Inside sealed enclosures

---

## 4. Concealment vs Accessibility

Good:
- Inside a drawer
- Under a shelf lip
- Behind a decorative object

Bad:
- Fully hidden with no clue
- Requiring force to access
- Near strong magnets or electronics

---

## 5. Environmental Considerations

- Bathrooms: use water-resistant tags
- Kitchens: avoid heat sources
- Outdoors: weatherproof only

Test every placement with:
- Multiple phone models
- Cases on and off

---

## 6. Testing Protocol

For each placed tag:
- Scan with at least two devices
- Scan with case on
- Confirm correct node loads
- Confirm gating behaves correctly

---

## 7. Final Thought

If a player asks:
> “Am I allowed to scan this?”

You’ve placed it correctly.

If they ask:
> “Why would anyone scan that?”

Reconsider placement.
