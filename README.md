# NFC Scavenger Hunt (iOS)

Private, offline-first family scavenger hunt app using NFC tags.

## Goals
- On-device only (no backend)
- Ordered progression
- Multi-age difficulty tracks
- NFC tags contain IDs only

## Repo Structure
- docs/        → planning, lessons, architecture
- design/      → UI, NFC mapping, wireframes
- ios-app/     → Xcode project lives here
- data/        → bundled JSON content
