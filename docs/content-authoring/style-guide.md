# Content Style Guide

This guide defines the tone, voice, and consistency rules for all scavenger hunt content.

The goal is a unified experience across ages, rooms, and nodes.

---

## 1. Narrative Voice

- Second person (“you”)
- Present tense
- Lightly theatrical
- Encouraging, never mocking

Preferred tone:
- Curious
- Brave
- Playful
- Slightly epic (but not cringe)

Avoid:
- Sarcasm
- Pop-culture references that will age badly
- Instructions that feel like homework

---

## 2. Age Track Expectations

### Kiddos
- Short sentences
- Concrete language
- Clear success feedback
- Gentle failure responses

### Tweens
- Riddles
- Simple logic
- Cause-and-effect reasoning

### Youths
- Wordplay
- Multi-step reasoning
- Light abstraction

### Adults
- Metaphor
- Lateral thinking
- Cultural or literary nods (subtle)

---

## 3. Success and Failure Messaging

### Success
- Celebrate effort
- Acknowledge cleverness
- Point forward

Example:
> “Well done, seeker. The house has noticed.”

### Failure
- Never shame
- Offer encouragement
- Suggest trying again or using a hint

Example:
> “Not quite—but you’re circling the truth.”

---

## 4. Clue Language Rules

- Do not use compass directions unless necessary
- Prefer sensory cues (sound, texture, light)
- Avoid exact distances
- Never reference file names, tag IDs, or node numbers

---

## 5. Consistency Rules

- Capitalization should be natural sentence case
- Avoid excessive punctuation
- Emojis are allowed sparingly for Kiddos only
- Maintain consistent terminology across nodes

---

## 6. Golden Rule

If a line sounds like a UI message, rewrite it.

If it sounds like a story whispered just loud enough to follow, keep it.
